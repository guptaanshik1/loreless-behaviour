Privacy Policy – gta6-clipper

Last updated: 22 November 2026

gta6-clipper is a personal tool used only by its owner (Loreless Behaviour) to upload the owner's own videos to the owner's own YouTube channel and Instagram account.

What data is used

  • An OAuth refresh token for the owner's YouTube account, with the youtube.upload scope only.
  • Video files, titles, descriptions and tags that the owner created.

How it is stored

Tokens are stored only on the owner's own computer in a file readable only by the owner. No data is sent to any server other than Google/YouTube and Meta/Instagram for the purpose of uploading the owner's videos. No data is sold, shared, or used for advertising.

Other users

The tool has no other users and collects no data about anyone else.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
